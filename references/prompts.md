# 长视频深度学习 · Prompt 模板（渐进式披露）

> 直接复制使用。{占位符} 由 agent 填入实际内容。

## explain（选中段落讲解）

```
你是一名严谨的讲解助手。下面是一段长视频逐字稿片段（含时间戳）：
---
{片段文本}
---
请：1) 用大白话解释其中的难点 / 专业概念；2) 补充必要的背景知识；
3) 若涉及争议或不同观点，指出分歧点。
不要复述原文，要补充信息增量。
```

## translate（中英对照）

```
将以下逐字稿译为自然英文，保留时间戳，输出中英对照两栏：
---
{原文}
---
```

## 章节生成

```
根据以下全片逐字稿，按话题切分 8–15 个章节，输出 JSON 数组：
[{"t_start":"00:00","t_end":"03:12","title":"...","summary":"一句话摘要"}]
要求：章节不重叠、覆盖全片、标题具体。
---
{全片逐字稿}
---
```

## 术语纠错（转写后补正）

```
你是一名字幕校对助手。下面是某{主题}视频的逐字稿片段（含时间戳）：
---
{片段文本}
---
已知正确术语（若有）：{术语表，如 checkAutoType / miscCodec / expectClass / FuzzJson}
请逐句比对，把听写错误的专有名词还原为正确写法，输出修正后的文本（保留时间戳）。
只改明显误听，不改口语风格；不确定的不要硬改，标注 [?] 留给人工确认。
```

## 视觉结合讲解（frames + 转写）

```
你是一名严谨的讲解助手。下面是一段长视频的逐字稿片段 + 对应画面帧：
---
{片段文本}
{帧图片或帧内容描述，如"03:00 处手绘的 checkAutoType 判断流程图"}
---
请结合画面（流程图/公式/代码/画面文字）解释难点；若画面与语音互补，指出"看这张图时重点看哪里"。
不要复述原文，要补充信息增量。
```

## 笔记生成（export）

```
基于以下逐字稿与章节，生成一份结构化学习笔记（markdown）：
核心观点 / 关键事实 / 个人可执行启发 / 待深挖问题。
语气像看完一场深度访谈后的复盘。
---
{逐字稿 + 章节}
---
```
